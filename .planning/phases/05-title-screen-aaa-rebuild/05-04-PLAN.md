    **Part A: Create UIVFXContainer** (namespace `VeilBreakers.UI.Core`)

    A plain C# utility class that manages named VFX layers with predictable z-ordering.

    Implementation:
    - `private readonly VisualElement _host` -- the container that holds all VFX layers
    - `private readonly Dictionary<string, VisualElement> _layers` -- named layer lookup
    - `private readonly List<string> _layerOrder` -- bottom-to-top z-order
    - Constructor: `UIVFXContainer(VisualElement host)` -- stores host reference
    - `public VisualElement GetOrCreateLayer(string layerName)` -- returns existing layer or creates new one. New layers are inserted at the correct z-position based on _layerOrder. If _layerOrder does not contain layerName, append to end.
    - `public void SetLayerOrder(params string[] layerNames)` -- defines the bottom-to-top z-order. Reorders existing layers to match.
    - `public void RemoveLayer(string layerName)` -- removes a layer from host and dictionaries
    - `public void ClearAll()` -- removes all layers from host, clears dictionaries

    For the title screen, the layer order (bottom to top) should be:
    1. "background" (video)
    2. "atmosphere" (fog, vignette, grunge)
    3. "particles" (embers, ash)
    4. "lightning" (strikes, flash)
    5. "logo" (glow, aura)
    6. "ui" (buttons, menu)

    Integration into TitleScreenVFX:
    - In the orchestrator's Initialize/Awake, create a UIVFXContainer with the root
    - Call `SetLayerOrder("background", "atmosphere", "particles", "lightning", "logo", "ui")`
    - Pass the container or individual layers to subsystem Initialize methods so they add their VisualElements to the correct layer instead of directly to root
    - This eliminates all `root.Insert(0, ...)` and `root.Add(...)` calls in subsystems -- they now use `_container.GetOrCreateLayer("particles").Add(element)` etc.

    **Part B: Create VERATitleAudio** (namespace `VeilBreakers.Audio`)

    A MonoBehaviour that replaces the sequential VERAInteractions() coroutine with weighted random selection.

    Implementation:
    - `[System.Serializable] private class InteractionDef`:
      - `public string id` -- unique identifier (e.g., "whisper_comment", "demon_cackle", "mysterious_hint", "vera_reacts")
      - `public AudioClip veraClip` -- VERA's voice clip (may be null if demon-only)
      - `public AudioClip demonClip` -- demon voice clip (may be null if VERA-only)
      - `public float weight = 1f` -- selection weight
      - `public float cooldown = 30f` -- minimum seconds before this interaction can repeat
      - `[System.NonSerialized] public float lastPlayedTime = -999f`
    - `[SerializeField] private InteractionDef[] _interactions` -- Inspector-configurable pool
    - `[SerializeField] private float _globalCooldown = 12f` -- minimum gap between ANY interaction
    - `[SerializeField] private int _historySize = 2` -- how many recent interactions to exclude
    - `private List<string> _recentHistory`
    - `private float _lastPlayTime`
    - `public InteractionDef SelectNext()` -- weighted random with cooldown + history exclusion
    - `private int WeightedRandom(List<float> weights)` -- cumulative weight selection
    - `public void StartInteractions()` -- starts the coroutine loop
    - `public void StopInteractions()` -- stops the coroutine
    - `private IEnumerator InteractionLoop()`:
      1. Wait 8-14 seconds (random initial delay)
      2. Loop:
         a. Call SelectNext()
         b. If null (all on cooldown), wait 5 seconds and retry
         c. Play veraClip and/or demonClip via AudioSource (respecting master volume)
         d. Wait for clip(s) to finish + 8-16 seconds random gap
         e. Repeat
    - Use VERASystem singleton for glitch/personality state checks if needed

    public static VisualElement SetupBlurGlow(Button button, Color glowColor, float blurRadius = 12f, float spread = 6f, float opacity = 0.15f)

        glow.pickingMode = PickingMode.Ignore;
