The material at `Assets/Resources/CharacterSelect/HeroThemes/VeilDissolvePlaceholder.mat` currently has:
- `m_Shader: {fileID: 0}` (no shader)
- `_NoiseTexture: {fileID: 0}` (no noise texture)

Fix by:
1. Assign the VeilDissolve shader reference to `m_Shader`. Find the shader's GUID by searching the .meta file for `Assets/Shaders/VeilDissolve.shader.meta`. The m_Shader field format is `{fileID: <shaderFileID>, guid: <shaderGUID>, type: 3}`.
2. Create a noise texture or use Unity's default white texture. The shader falls back to white (identity noise) which produces a clean linear dissolve. For a more organic dissolve, generate a simple Perlin noise Texture2D via an Editor script and reference it. But white default is acceptable for now -- the dissolve will still work, just with a cleaner edge rather than organic noise. Keep `_NoiseTexture: {fileID: 0}` if no noise texture is available (shader uses "white" default).

Read `Assets/Shaders/VeilDissolve.shader.meta` to get the GUID, then update the material YAML:
```yaml

```

HeroStageController.SwapHeroModel() instantiates the model and stores it in `_currentModel`. After instantiation, get the Renderer and pass it to VeilDissolveController.Init().

Add to HeroStageController:

2. Add a public property or method to receive the controller reference: `public void SetDissolveController(VeilDissolveController ctrl) => _dissolveController = ctrl;`
3. In SwapHeroModel(), after `_currentModel` is instantiated and set up (after the layer/scale/rotation lines, around line 261), add:
```csharp

```
