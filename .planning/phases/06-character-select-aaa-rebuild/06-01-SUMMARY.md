## Decisions Made
- Editor script approach over hand-authored YAML: VolumeProfile assets use Unity's internal GUID-based serialization that cannot be reliably hand-crafted from outside the editor
- Each profile includes 5 overrides (Bloom, Vignette, DepthOfField, ColorAdjustments, ChromaticAberration) matching what VolumeProfileTransitioner.CacheTargetValues reads
- ChromaticAberration left at 0 in all profiles because VolumeProfileTransitioner reads it from HeroThemeConfig.chromaticAberrationIntensity directly (only Nyx has 0.15)

## User Setup Required

**The VolumeProfile assets must be generated by running the editor script in Unity:**
1. Open Unity Editor
2. Run menu: **Tools > Generate Hero Volume Profiles**
3. Verify 4 new assets in `Assets/Resources/CharacterSelect/HeroThemes/`: VolProfile_Vex.asset, VolProfile_Seraphina.asset, VolProfile_Orion.asset, VolProfile_Nyx.asset
4. Verify each HeroThemeConfig SO now has a non-null volumeProfile reference in the Inspector
5. The editor script can be deleted after successful generation if desired
