**Step 2: Write VeilDissolve.shader**

Create `Assets/Shaders/VeilDissolve.shader` -- a URP Lit-based HLSL dissolve shader with path "VeilBreakers/VeilDissolve".

Shader properties:
```hlsl
Properties
{
    // Standard URP Lit surface properties
    _BaseMap ("Base Map", 2D) = "white" {}
    _BaseColor ("Base Color", Color) = (1,1,1,1)
    _Metallic ("Metallic", Range(0,1)) = 0
    _Smoothness ("Smoothness", Range(0,1)) = 0.5
    _BumpMap ("Normal Map", 2D) = "bump" {}
    _BumpScale ("Normal Scale", Float) = 1.0

    // Dissolve properties
    _DissolveThreshold ("Dissolve Threshold", Range(0, 1)) = 0
    _NoiseTexture ("Noise Texture", 2D) = "white" {}
    _NoiseScale ("Noise Scale", Float) = 1.0
    _DissolveEdgeWidth ("Edge Width", Range(0, 0.15)) = 0.05
    _DissolveEdgeColor ("Edge Color (HDR)", Color) = (1, 0.5, 0, 1)
    _EmissionIntensity ("Emission Intensity", Float) = 3.0
}
```

SubShader structure:
- Tags: `"RenderPipeline" = "UniversalPipeline"`, `"RenderType" = "Opaque"`, `"Queue" = "Geometry"`
- LOD 300
- Two passes: Forward Lit pass + ShadowCaster pass

Forward Lit pass fragment shader logic:
1. Sample `_NoiseTexture` at `uv * _NoiseScale` to get noise value (0-1)
2. `clip(noise - _DissolveThreshold)` -- hard alpha clip, binary discard (no transparency, prevents z-fighting per RESEARCH.md pitfall 7)
3. Calculate edge factor: `float edge = 1.0 - smoothstep(_DissolveThreshold, _DissolveThreshold + _DissolveEdgeWidth, noise)`
4. Add HDR emission on dissolve edge: `emission += _DissolveEdgeColor.rgb * _EmissionIntensity * edge`
5. When `_DissolveThreshold == 0`, shader behaves as standard URP Lit (no dissolve, no edge glow)

ShadowCaster pass:
- Must also sample noise and call `clip(noise - _DissolveThreshold)` so shadows dissolve in sync with geometry

Use URP shader includes:
```hlsl
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Lighting.hlsl"
```

CBUFFER block for SRP Batcher compatibility:
```hlsl
CBUFFER_START(UnityPerMaterial)
    float4 _BaseMap_ST;
    half4 _BaseColor;
    half _Metallic;
    half _Smoothness;
    half _BumpScale;
    half _DissolveThreshold;
    float _NoiseScale;
    half _DissolveEdgeWidth;
    half4 _DissolveEdgeColor;
    half _EmissionIntensity;
CBUFFER_END
```

All dissolve properties must be MaterialPropertyBlock-compatible (they are by default with the CBUFFER pattern). The controller will use `_renderer.SetPropertyBlock(_mpb)` to set `_DissolveThreshold`, `_DissolveEdgeColor`, and `_NoiseScale` per hero without creating material instances.
