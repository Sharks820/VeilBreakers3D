**A. Create VeilCrack.shader**

File: `Assets/Shaders/VeilCrack.shader`
Shader name: `"VeilBreakers/VeilCrack"`

Purpose: Full-screen procedural crack pattern for embark cinematic. Rendered as a full-screen overlay (via UI Toolkit VisualElement with background or via Full Screen Pass Renderer Feature).

Since implementing a Full Screen Pass Renderer Feature requires Editor configuration that can't be done via code alone, use a simpler approach: render the crack pattern on a full-screen UI Toolkit VisualElement via a RenderTexture, or use a world-space quad positioned in front of the camera.

**Recommended approach:** Use this shader on a full-screen VisualElement's background image via a RenderTexture driven by a secondary camera, OR implement it as an unlit transparent shader on a world-space quad in the hero stage.

Shader properties:
```hlsl
Properties
{
    _CrackProgress ("Crack Progress", Range(0, 1)) = 0
    _CrackColor ("Crack Color (HDR)", Color) = (1, 0.5, 0, 1)
    _CrackWidth ("Crack Width", Range(0.001, 0.05)) = 0.01
    _CrackGlowIntensity ("Glow Intensity", Float) = 5.0
    _ShatterProgress ("Shatter Progress", Range(0, 1)) = 0
    _NoiseScale ("Noise Scale", Float) = 8.0
    _CellScale ("Cell Scale", Float) = 4.0
    _BackgroundAlpha ("Background Alpha", Range(0, 1)) = 0
}
```

SubShader:
- Tags: `"RenderPipeline" = "UniversalPipeline"`, `"RenderType" = "Transparent"`, `"Queue" = "Transparent+100"`
- Blend SrcAlpha OneMinusSrcAlpha
- ZWrite Off, ZTest Always (always on top)
- Cull Off

Fragment shader logic:
1. Generate Voronoi noise cells from UV coordinates scaled by `_CellScale`
2. `_CrackProgress` controls how many cracks are visible (0 = none, 1 = fully cracked)
   - Use Voronoi edge distance: pixels near cell boundaries are "cracks"
   - Crack visibility: `float crackMask = step(edgeDistance, _CrackWidth * _CrackProgress)`
3. Cracks glow in `_CrackColor * _CrackGlowIntensity` (HDR)
4. `_ShatterProgress` controls fragment displacement: cells shift outward from center as shatter progresses
5. Background alpha: `_BackgroundAlpha` for the white-out fade at the end
6. Final color: crack glow + background alpha

Voronoi implementation (standard technique):
```hlsl
float2 VoronoiHash(float2 p)
{
    p = float2(dot(p, float2(127.1, 311.7)), dot(p, float2(269.5, 183.3)));
    return frac(sin(p) * 43758.5453);
}

float Voronoi(float2 uv, float scale)
{
    float2 g = floor(uv * scale);
    float2 f = frac(uv * scale);
    float minDist = 1.0;
    float secondDist = 1.0;

    for (int y = -1; y <= 1; y++)
    for (int x = -1; x <= 1; x++)
    {
        float2 offset = float2(x, y);
        float2 cell = VoronoiHash(g + offset);
        float2 diff = offset + cell - f;
        float dist = length(diff);
        if (dist < minDist) { secondDist = minDist; minDist = dist; }
        else if (dist < secondDist) { secondDist = dist; }
    }
    return secondDist - minDist; // Edge distance
}
```

SRP Batcher compatibility: Include all properties in CBUFFER_START(UnityPerMaterial).

```csharp
/// <summary>
/// Spreads procedural cracks from screen center. Progress 0-1.
/// </summary>
public Tween PlayCrackSpread(float duration, Color accentColor)
{
    _mpb.SetColor(kCrackColor, accentColor);
    _mpb.SetFloat(kCrackProgress, 0f);
    _fullScreenQuadRenderer.SetPropertyBlock(_mpb);

    return Tween.Custom(this, 0f, 1f, duration, Ease.InQuad,
        (ctrl, val) => {
            ctrl._mpb.SetFloat(kCrackProgress, val);
            ctrl._fullScreenQuadRenderer.SetPropertyBlock(ctrl._mpb);
        });
}

/// <summary>
/// Shatters the cracks outward with fragment displacement + particle burst.
/// </summary>
public Tween PlayShatter(Color accentColor, float duration = 0.3f)
{
    if (_shatterParticles != null)
    {
        var main = _shatterParticles.main;
        main.startColor = accentColor;
        _shatterParticles.Play();
    }

    return Tween.Custom(this, 0f, 1f, duration, Ease.OutQuad,
        (ctrl, val) => {
            ctrl._mpb.SetFloat(kShatterProgress, val);
            ctrl._fullScreenQuadRenderer.SetPropertyBlock(ctrl._mpb);
        });
}

/// <summary>
/// Fades to white overlay (for scene transition).
/// </summary>
public Tween PlayWhiteOut(float duration = 0.2f)
{
    return Tween.Custom(this, 0f, 1f, duration, Ease.InQuad,
        (ctrl, val) => {
            ctrl._mpb.SetFloat(kBackgroundAlpha, val);
            ctrl._fullScreenQuadRenderer.SetPropertyBlock(ctrl._mpb);
        });
}

/// <summary>
/// Materializes from a shattered/white state back to clear. For title screen reuse.
/// </summary>
public Tween PlayMaterialize(Color accentColor, float duration = 1f)
```

```csharp
public void PlayEmbarkCinematic(HeroThemeConfig theme, string heroName, string heroTitle)
{
    _cinematicSequence?.Stop();

    // Create centered name label for the flash
    CreateCinematicNameLabel(heroName);

    _cinematicSequence = Sequence.Create()
        // t=0ms: Hero accent flash
        .Insert(0f, BuildAccentFlash(theme.primaryColor))

        // t=100ms: Camera dolly + bloom
        .InsertCallback(0.1f, () => _stageController.DollyToHero(40f, 0.4f))

        // t=300ms: UI panels dismiss
        .Insert(0.3f, Tween.StyleTranslate(_leftPanel, new Translate(-300, 0), 0.2f, Ease.InCubic))
        .Insert(0.3f, Tween.StyleTranslate(_rightPanel, new Translate(300, 0), 0.2f, Ease.InCubic))
        .Insert(0.3f, Tween.StyleTranslate(_carousel, new Translate(0, 200), 0.2f, Ease.InCubic))

        // t=500ms: Veil crack spread
        .Insert(0.5f, _veilTransition.PlayCrackSpread(0.3f, theme.primaryColor))

        // t=600ms: Hero name glitch text reveal
        .Insert(0.6f, GlitchTextEffect.BuildGlitchReveal(_cinematicNameLabel, heroName, theme.glitchResolveSpeed))

        // t=800ms: Shatter + name fade
        .Insert(0.8f, _veilTransition.PlayShatter(theme.primaryColor, 0.2f))
        .Insert(0.8f, Tween.StyleOpacity(_cinematicNameLabel, 0f, 0.15f, Ease.InQuad))

        // t=1000ms: White-out
        .Insert(1.0f, _veilTransition.PlayWhiteOut(0.2f))

        // t=1200ms: Complete -- fire OnCinematicComplete (NOT OnTransitionComplete)
        .ChainCallback(() => OnCinematicComplete?.Invoke());
}
```

**D. Wire into existing embark flow with TaskCompletionSource**

The existing flow is: HoldToEmbarkController fires OnEmbarkTriggered -> CharacterSelectManager.TriggerEmbark() -> ExecuteEmbarkAsync() -> save + scene load.

In CharacterSelectManager:

1. Add a `[SerializeField] private EmbarkCinematicController _embarkCinematic;` field declaration.

2. Modify ExecuteEmbarkAsync() to play the cinematic FIRST, then await its completion before proceeding to save/load. Since PrimeTween Sequence does NOT return a Task (it's fire-and-forget with callbacks), bridge using TaskCompletionSource:

```csharp
private async void ExecuteEmbarkAsync()
{
    // ... existing pre-embark logic ...

    // Play cinematic and await completion via TaskCompletionSource bridge
    if (_embarkCinematic != null)
    {
        var tcs = new System.Threading.Tasks.TaskCompletionSource<bool>();

        // Subscribe ONCE to the cinematic's completion event
        void OnComplete()
        {
            _embarkCinematic.OnCinematicComplete -= OnComplete;
            tcs.TrySetResult(true);
        }
        _embarkCinematic.OnCinematicComplete += OnComplete;

        // Get current hero theme from the transitioner
        var theme = _themeTransitioner.GetCurrentTheme();
        _embarkCinematic.PlayEmbarkCinematic(theme, heroName, heroTitle);

        // Await the cinematic completion (~1.2s)
        await tcs.Task;
    }

    // ... existing save + scene load logic continues AFTER cinematic ...
}
```

This pattern:
- Creates a TaskCompletionSource<bool> before starting the cinematic
- Subscribes a one-shot handler to OnCinematicComplete that completes the TCS
- Starts the cinematic (which runs via PrimeTween internally)
- `await tcs.Task` suspends until the ChainCallback fires OnCinematicComplete
- Then save/load proceeds with the white overlay already at full opacity

IMPORTANT: The `_embarkCinematic` field MUST be `[SerializeField] private EmbarkCinematicController _embarkCinematic;` so it can be assigned in the Inspector. Without this field declaration, the wiring cannot work.
