**A. Create VolumeProfileTransitioner.cs**

File: `Assets/Scripts/UI/CharacterSelect/VolumeProfileTransitioner.cs`
Namespace: `VeilBreakers.UI.CharacterSelect`
Class: `public class VolumeProfileTransitioner : MonoBehaviour`

Purpose: Lerps URP Volume overrides between per-hero profiles using PrimeTween Tween.Custom.

Required using statements:
```csharp
using UnityEngine;
using UnityEngine.Rendering;
using UnityEngine.Rendering.Universal;
using PrimeTween;
```

Fields:
```csharp
[SerializeField] private Volume _volume; // Scene volume component
private Bloom _bloom;
private Vignette _vignette;
private DepthOfField _dof;
private ColorAdjustments _colorAdj;
private ChromaticAberration _chromatic;

// Cached source values for lerp (snapshot current state)
private float _srcBloomIntensity, _dstBloomIntensity;
private Color _srcBloomTint, _dstBloomTint;
private float _srcVignetteIntensity, _dstVignetteIntensity;
private Color _srcVignetteColor, _dstVignetteColor;
private float _srcDofStart, _dstDofStart;
private float _srcDofEnd, _dstDofEnd;
private float _srcColorTemp, _dstColorTemp;
private float _srcColorSat, _dstColorSat;
private Color _srcColorFilter, _dstColorFilter;
private float _srcChromaticIntensity, _dstChromaticIntensity;
private Tween _activeTween;
```

Awake():
- CRITICAL: Instantiate volume profile at runtime to prevent Editor asset mutation (per RESEARCH.md pitfall 1): `_volume.profile = Instantiate(_volume.sharedProfile);`
- Cache all override references via `profile.TryGet(out _bloom)` etc.
- Enable overrideState on ALL properties that will be animated (per RESEARCH.md pitfall 2)

Public API:
```csharp
/// <summary>
/// Lerps all volume overrides from current values to the target hero's profile values.
/// </summary>
public Tween LerpTo(HeroThemeConfig theme, float duration = 0.8f)
```

LerpTo implementation:
1. Stop any active tween: `_activeTween.Stop()`
2. Call `CacheSourceValues()` -- snapshots current override values
3. Call `CacheTargetValues(theme)` -- reads target values from the theme's volumeProfile
4. Start lerp: `_activeTween = Tween.Custom(this, 0f, 1f, duration, ease: Ease.InOutSine, onValueChange: (target, t) => target.ApplyLerp(t));`
5. Return the tween for sequence composition

CacheTargetValues(HeroThemeConfig theme):
- Load target values from theme.volumeProfile via TryGet<T>
- Read Bloom: intensity, tint
- Read Vignette: intensity, color
- Read DepthOfField: gaussianStart, gaussianEnd (or focusDistance depending on DoF mode)
- Read ColorAdjustments: colorFilter, postExposure, saturation
- Read ChromaticAberration: intensity (from theme.chromaticAberrationIntensity directly, since Nyx is the only one with > 0)

ApplyLerp(float t):
- For each cached property pair: `_bloom.intensity.value = Mathf.Lerp(_srcBloomIntensity, _dstBloomIntensity, t);`
- Use Color.Lerp for color properties
- Always ensure `overrideState = true` before setting value

OnDestroy():
- Destroy the instantiated profile to prevent memory leak: `if (_volume != null && _volume.profile != null) Destroy(_volume.profile);`

**B. Create GlitchTextEffect.cs**

File: `Assets/Scripts/UI/CharacterSelect/GlitchTextEffect.cs`
Namespace: `VeilBreakers.UI.CharacterSelect`
Class: `public class GlitchTextEffect`
(Pure C# class, not MonoBehaviour)

Purpose: Builds PrimeTween sequences that scramble text through glitch characters then resolve character-by-character.

Constants:
```csharp
private static readonly char[] kGlitchChars = new char[]
{
    '\u2588', '\u2591', '\u2592', '\u2593', '\u2580', '\u2584',
    '\u258C', '\u2590', '\u25A0', '\u25B2', '\u2666', '\u00A8'
};
```

Public API:
```csharp
/// <summary>
/// Builds a PrimeTween Sequence that glitch-reveals text on a Label.
/// Characters scramble through block drawing characters then resolve left-to-right.
/// </summary>
/// <param name="label">The UI Toolkit Label to animate</param>
/// <param name="targetText">The final resolved text</param>
/// <param name="resolveSpeed">Characters per second (Vex=60, Nyx=35)</param>
/// <returns>PrimeTween Sequence for composition into larger timelines</returns>
public static Sequence BuildGlitchReveal(Label label, string targetText, float resolveSpeed = 50f)
```

Implementation:
1. Initialize label text to all glitch characters: `label.text = new string(kGlitchChars[0], targetText.Length)`
2. Create Sequence
3. For each character index i:
   - Calculate start time: `float startTime = i / resolveSpeed`
   - Insert a Tween.Custom at startTime that:
     - During t < 0.7f: sets `chars[i]` to random glitch char (use `kGlitchChars[Mathf.FloorToInt(t * kGlitchChars.Length) % kGlitchChars.Length]` for deterministic-ish cycling instead of Random to avoid allocation)
     - At t >= 0.7f: resolves to `targetText[i]`
   - Duration per char: ~3 / resolveSpeed seconds (glitch frames before resolve)

IMPORTANT: Avoid `string.ToCharArray()` allocation in the hot loop. Pre-allocate a `char[]` buffer sized to targetText.Length at sequence build time. Use captured reference in the closure. The Tween.Custom target parameter pattern avoids closure allocation for the tween itself.

Actually, to avoid per-frame string allocation: since Label.text setter creates a string anyway, the most practical approach is to use a pre-allocated char[] buffer and create the string once per frame update. This is acceptable since glitch text runs for ~250ms total and is not a hot path.
