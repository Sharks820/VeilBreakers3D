<objective>
Audit and fix all USS transition declarations to use only GPU-accelerated properties, and set UsageHints.DynamicTransform on all animated VisualElements.

Purpose: `transition: all` in CharacterSelect.uss causes layout recalculation every frame during transitions (Yoga engine recomputes width, height, margin, padding). Rewriting to explicit property lists (translate, scale, opacity, color, border-color) eliminates layout thrashing. Setting UsageHints.DynamicTransform on animated elements enables GPU-accelerated compositing, avoiding one-frame CPU penalties when transitions start.

Output: CharacterSelect.uss with all transitions rewritten to explicit property lists. CharacterSelectManager.cs with SetAnimationHints() method setting DynamicTransform on all interactive/animated elements.
</objective>

    1. **Create the method:**
       ```csharp
       private void SetAnimationHints()
       {
           SetHint(_root.Q<VisualElement>("hero-info-panel"));
           SetHint(_root.Q<VisualElement>("stats-panel"));
           SetHint(_root.Q<Button>("btn-back"));
           SetHint(_root.Q<Button>("btn-embark"));
           SetHint(_root.Q<VisualElement>("embark-hex-bg"));
           SetHint(_root.Q<VisualElement>("embark-glow"));
           SetHint(_root.Q<Button>("btn-prev"));
           SetHint(_root.Q<Button>("btn-next"));
           SetHint(_root.Q<VisualElement>("confirm-overlay"));

           // Ability slots (hover transitions)
           _root.Query<VisualElement>(className: "ability-slot").ForEach(SetHint);

           // Hero cards (scale on hover/selected)
           _root.Query<VisualElement>(className: "hero-card").ForEach(SetHint);

           // Nav arrows (scale on hover)
           _root.Query<VisualElement>(className: "nav-arrow").ForEach(SetHint);

           // Glass panels (border-color transitions)
           _root.Query<VisualElement>(className: "glass-panel").ForEach(SetHint);

           // Fog particles (background-color transition)
           _root.Query<VisualElement>(className: "fog-particles").ForEach(SetHint);
       }

       private static void SetHint(VisualElement el)
       {
           if (el != null) el.usageHints = UsageHints.DynamicTransform;
       }
       ```

    2. **Call `SetAnimationHints()`** in the initialization flow, AFTER `CacheUIReferences()` (or equivalent) has run but BEFORE any transitions can fire. Place it in `OnEnable()` or `Initialize()`, right after element caching.
