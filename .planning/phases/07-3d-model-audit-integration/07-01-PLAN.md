  <action>
Create `Assets/Editor/VeilBreakers/VB_ModelAuditor.cs` with namespace `VeilBreakers.Editor`.

Implement TWO MenuItem methods:

**MenuItem 1: "VeilBreakers/Audit All Models"**
- Use `AssetDatabase.FindAssets("t:Model", new[] { "Assets/Art/Models" })` to find all imported model assets
- For each model:
  - Get path, file size (via FileInfo), import settings via `ModelImporter`
  - Read polycount from `ModelImporter.meshes[0].vertexCount` (if available) -- NOTE: Unity's ModelImporter may not expose vertex count directly. If not available, log "polycount: requires Unity runtime" and note the file size as a proxy
  - Log rig status: check if `ModelImporter.isReadable`, `ModelImporter.animationType != AnimationType.None`
  - Check UV: `ModelImporter.meshes[0].uv` (may require reading the imported mesh at runtime via AssetDatabase.LoadAssetAtPath)
  - Check normals: `ModelImporter.normalImportMode`
  - Group results by character name (Nyx, Orion, Seraphina, Bloodshade, Grimthorn, Voltgeist)
  - Identify v4 (latest) variant for each character
  - Print formatted table to Debug.Log with columns: Character | Version | Path | FileSize | Rig | Normals | Notes
  - Flag v1-v3 as "stale -- candidate for deletion"

**MenuItem 2: "VeilBreakers/Wire Hero Models"**
- Define a dictionary mapping heroId to GLB path:
  ```
  "nyx" -> "Assets/Art/Models/Heroes/Nyx/model_v4_pbr.glb"
  "orion" -> "Assets/Art/Models/Heroes/Orion/model_v4_pbr.glb"
  "seraphina" -> "Assets/Art/Models/Heroes/Seraphina/model_v4_pbr.glb"
  ```
- For each mapping:
  - Load the HeroDisplayConfig SO via `AssetDatabase.LoadAssetAtPath<HeroDisplayConfig>("Assets/Resources/CharacterSelect/HeroDisplayConfigs/{HeroName}DisplayConfig.asset")`
  - Load the model asset via `AssetDatabase.LoadAssetAtPath<GameObject>(glbPath)`
  - If model asset is null: log error "GLB not imported yet -- import first", continue
  - Use `SerializedObject` + `Undo.RecordObject` to set `modelPrefab` to the model's root GameObject
  - Save with `EditorUtility.SetDirty` + `AssetDatabase.SaveAssetDatabase`
  - Log: "Wired {heroId} modelPrefab -> {glbPath}"
- After wiring, check Vex and log warning: "Vex model not found at Assets/Art/Models/Heroes/Vex/ -- no GLB exists. Keeping placeholder."
- Print summary: "Wired 3/4 hero models. Vex remains placeholder (model missing)."

DO NOT use `Shader.Find` in editor scripts (UNLESS cached). DO NOT create GameObjects in MenuItem methods that should only modify assets.

Code style per CLAUDE.md: `k` prefix for constants, `_` prefix for privates, PascalCase for properties.
