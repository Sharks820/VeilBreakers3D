# DCC Bridge Templates

This folder contains templates and utilities for Blender workflow.

## Available Templates

### Character Template (`veilbreakers_character_template.py`)

A Blender Python script that sets up a game-ready character scene.

**Features:**
- Metric units (1 unit = 1 meter)
- 60fps frame rate for game animations
- Three-point lighting setup
- Scale reference objects
- Organized collections structure

**Usage:**
1. Open Blender
2. Go to Scripting workspace
3. Open `veilbreakers_character_template.py`
4. Click "Run Script"

**Collections Created:**
- `Character` - For character mesh and rig
- `Reference` - Grid and measurement helpers
- `Lighting` - Three-point lighting setup
- `Export_Character` - Mark objects here for export
